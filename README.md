# VoiceFX App Project

本项目方向为：基于 MATLAB App Designer 的实时人声变换、音乐音效处理与信号可视化系统。

当前阶段仅进行基础项目准备，用于保存说明文档、样例音频和后续实验结果，不实现具体功能。

后续方案确认后，项目可能逐步加入文件读取、实时监听、滤波、音效、调制解调和信号可视化等模块。

当前不编写 MATLAB 功能函数，不创建 App Designer 文件，也不接入具体音频处理算法。

## 当前阶段

本阶段为第一阶段工程框架搭建：只建立目录结构、统一接口和可运行的占位函数，方便后续分模块开发。

文件模式和实时模式应共用同一条 frame 级处理链。文件模式通过 `processAudioFile` 将整段音频分帧，并逐帧调用 `processAudioFrame`；实时模式后续也应直接调用 `processAudioFrame`，避免维护两套处理逻辑。

声线风格化、音效处理和空间效果不是二选一关系，而是在同一条处理链中串联组合。后续可支持类似“男声风格 + 电话音”“儿童/少年声线 + Reverb”“老年声线 + Lo-fi”“匿名采访 + 对讲机”“机器人声线 + Bitcrusher”等组合。

当前所有模块只实现接口壳或 pass-through 占位，不实现具体男声/女声、滤波、降噪、音效、调制解调或实时监听算法。

## 后续开发顺序建议

1. 先确认 `config`、`state` 和 `processAudioFrame` 的统一接口。
2. 再逐个补充 `modules/` 中的独立算法模块。
3. 每新增一个模块先做小测试，再接入文件模式。
4. 文件模式稳定后，再接入 realtime/ 和 App Designer 回调。
5. App 回调只负责 UI 参数、调用核心函数和显示结果，不直接写核心算法。
